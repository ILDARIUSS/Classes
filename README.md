# Магазин товаров (Категории и Продукты)

Этот проект реализует простую модель магазина, включая товары и категории.

## 📌 Функционал

- Класс `Product`:
  - Название (`name`)
  - Описание (`description`)
  - Цена (`price`) с проверкой через `@property`
  - Количество (`quantity`)
  - Класс-метод `new_product()`

- Класс `Category`:
  - Название (`name`)
  - Описание (`description`)
  - Приватный список товаров (`_products`)
  - Метод `add_product()`
  - Геттер `products` для вывода списка товаров
  - Подсчёт всех созданных категорий и товаров
