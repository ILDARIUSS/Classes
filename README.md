# 🛒 Магазин товаров

## 📌 Описание проекта
Проект представляет собой систему управления товарами в магазине. Реализованы базовые классы товаров, их категории, а также механизмы проверки типов, сложения товаров и управления списком товаров в категориях.

## 🔥 Функциональность:
- 📦 **Создание категорий товаров** с возможностью добавления товаров.
- 📌 **Базовый класс `BaseProduct`** с основными атрибутами:
  - название,
  - описание,
  - цена,
  - количество.
- ➕ **Класс `Product`** (универсальный товар), наследующий `BaseProduct` и использующий `PrintMixin`.
- 📱 **Класс-наследник `Smartphone`** (Смартфон), расширенный атрибутами:
  - производительность,
  - модель,
  - объем встроенной памяти,
  - цвет.
- 🌿 **Класс-наследник `LawnGrass`** (Газонная трава), имеющий дополнительные атрибуты:
  - страна-производитель,
  - срок прорастания,
  - цвет.
- ➕ **Магические методы:**
  - `__str__` — строковое представление объектов,
  - `__add__` — сложение товаров только одинаковых классов (суммируется стоимость всех товаров в наличии).
- 🛑 **Ограничения:**
  - Нельзя складывать товары разных типов (`TypeError`).
  - Проверка типов при добавлении товаров в категории (`isinstance()`, `issubclass()`).
- 📢 **Миксин `PrintMixin`**, который при создании объекта выводит в консоль информацию о нем.
- ✅ **Полное тестирование кода** с покрытием **более 75%**.
